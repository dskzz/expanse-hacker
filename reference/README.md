# reference

Design-facing docs for AI and human collaborators: gameplay mechanics derived from
the SolNet RFCs, mod/game design notes, glossaries, exploit-to-mechanic mappings.

Source of truth for the RFCs themselves lives in `docs/rfcs/`. Put summaries,
excerpts, or gameplay-specific distillations here — not full RFC text.

(Historical note: this used to say the Obsidian vault, `G:\obsidian\vaults\
solHacker`. That vault is frozen historical material from the project's
original GPT-era notes and was never this repo's live source — `docs/rfcs/`
is.)
