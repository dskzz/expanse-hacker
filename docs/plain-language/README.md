# Plain-Language RFC Companions

Plain-English write-ups of every graduated SolNet RFC, paired with
"where to look for exploits" hints aimed at a reader who doesn't want to
parse formal RFC voice first — a player, a GM, or a new designer joining
the project.

Each file has three parts:

- **What this actually does** — the RFC's real content, in plain terms.
- **Where to look for exploits** — concrete, narrative-friendly hints
  at the soft spots the RFC itself describes or implies. Where a formal
  companion doc already exists under `docs/rfc-companions/`, these are
  a simplified translation of its exploit material; where none exists
  yet, they're derived directly from the RFC's own text.
- **What's deliberately out of scope here** — what this RFC doesn't
  cover, and which other document actually owns that piece.

The canonical source of record for any RFC is always its Markdown file
under `docs/vault/New RFCs/`. These are a reader's digest of that
source, kept in sync manually — if the two ever disagree, the RFC wins.
