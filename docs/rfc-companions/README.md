# RFC Companion Docs

Plain Markdown copies of the SolNet RFC Companion documents — exploit
classes, mission hooks, game structures, software tools, and schemas-to-
craft for each graduated RFC.

Non-canonical GM/design reference material, not part of the in-fiction
RFC corpus in `docs/rfc-html/`. Kept as plain `.md` here — no styled HTML
rendering, unlike the RFCs themselves.

The canonical source of record for any companion document is always its
Markdown file under `docs/vault/RFC Companion/`. A file here is a copy,
kept in sync manually.
