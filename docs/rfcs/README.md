# SolNet RFCs — Canonical Source

The actual, live, canonical Markdown source for every graduated SolNet RFC.
This is where edits, fixes, and new drafts land once they graduate from a
live Claude Artifact draft.

`docs/rfc-html/` renders these as styled, read-only pages for a person to
read comfortably. `docs/rfc-companions/` holds the non-canonical GM/design
companion material (exploits, mission hooks) for each one. `docs/plain-
language/` holds reader's-digest versions for players/GMs who don't want
to parse RFC voice. All three are derived from what's in this folder — if
any of them ever disagrees with the Markdown here, this folder wins.

This folder did not exist until 2026-11-20. Before that, this content
lived under `docs/vault/New RFCs/`, which turned out to be the wrong
place — the vault (both the copy checked into this repo and the real one
on the user's own machine, `G:\obsidian\vaults\solHacker`) is frozen
historical material from the project's original GPT-era notes and is
never edited by this repo. The files here were copied from that vault
snapshot at the point this folder was created; the vault copy was left
as-is and is no longer the thing anyone should edit.
