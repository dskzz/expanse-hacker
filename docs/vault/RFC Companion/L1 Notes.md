# ✔️ **Optional L1 expansions (not required, only if you want them)**

These are _nice‑to‑have_ but not required for a complete L1:

### **1. RFC‑2354 — L1 Error Codes & Diagnostics**

Defines L1‑specific error codes (distinct from L0 and L2).

### **2. RFC‑2355 — L1 Congestion & Backpressure Behavior**

How relays signal congestion at the Data‑Link level.

### **3. RFC‑2356 — L1 Session Continuity Hints**

Hints for maintaining continuity across relay hops.

### **4. RFC‑2357 — L1 Link‑Local Discovery**

A tiny discovery protocol for immediate neighbors.

### **5. RFC‑2358 — L1 Test Vectors & Reference Frames**

Binary examples for implementers.

### **6. RFC‑2359 — L1 Compliance Profiles**

Defines “minimal,” “relay,” “personal device,” and “expanse” profiles.

Again: **none of these are required.** They’re expansions if you want more depth or more gameplay hooks.
