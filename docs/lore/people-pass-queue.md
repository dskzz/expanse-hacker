# People Pass Queue

Status: tracking doc, created 2026-11-24. Per the standing agreement
to finish the big structural worldbuilding passes (corporations,
politics, stations) before turning to named individuals, this file
collects every role/figure the corpus has already implied or
explicitly flagged as needing a name later — so nothing gets lost
between now and whenever the people pass actually happens. Add to
this list as new unnamed roles come up; strike entries once named
(moving the name into its proper home file, not leaving it only
here).
