# RFC HTML Renderings

Hand-maintained, reader-facing HTML copies of graduated SolNet RFCs — styled,
static, and read-only. These are for a person to open and read comfortably;
they are not generated build output (see `/build/`, which is Godot's
exported/packaged game builds and is a different thing entirely).

The canonical source of record for any RFC is always its Markdown file under
`docs/vault/New RFCs/`. A file here is a rendering of that source, kept in
sync manually — if the two ever disagree, the Markdown wins.
